# Server-wide asset and data sources

14 October 2026 — owner supplied these as sources for the **whole server**, not only sabers/farming. They are discovery/reference sources, not bulk download or purchase approval.

| Source | Intended project-wide use | Evidence / limits |
|---|---|---|
| [dergreif's Star Wars downloadable assets collection](https://sketchfab.com/dergreif/collections/star-wars-downloadable-assets-d92d41b214ea460d81c90a7caa8ee0d8) | Find props, creatures, vehicles, buildings and equipment across server features | Direct collection fetch returned 403 this pass. Collection owner is not necessarily asset creator; every chosen item needs original page, exact licence, contributors and origin audit. Downloadable does not mean open or portable |
| [CGTrader Blender Star Wars catalogue](https://www.cgtrader.com/3d-models/blender-star-wars) | Discover editable model sources across the server | Page readable, mixes free and paid items. Blender format/low-poly/rigged labels do not establish rights or SWG compatibility. Check individual licence, original creation, included textures/rig and redistribution terms; no purchases or blanket download authorization |
| [SWAPI](https://swapi.dev/) / [documentation](https://swapi.dev/documentation) | Structured reference IDs/fields for characters, species, planets, ships and vehicles; possible authoring-tool lookup | Data API, not model/texture library. Does not replace Wookieepedia Legends as project's preferred lore source; verify continuity and licence/provenance of selected data before copying. Screenshot's Wookiee-format claim is a tool feature, not Wookieepedia access or a lore accuracy guarantee |
| [swgoh-utils](https://github.com/swgoh-utils) / [SWGOH Comlink](https://github.com/swgoh-utils/swgoh-comlink) | Investigate tooling/data workflows or reference catalogues for Galaxy of Heroes | Different game from SWG. Source-code licence is separate from EA/CG game data/art rights. No assumption of art export, creature meshes or transferable balance formulas. No service deployed, credentials requested or game assets fetched |

Scope: these sources should be consulted for future content gaps throughout the server, alongside creator-primary CC0/CC BY libraries already recorded. Prefer unbranded industrial frontier replacements where practical, per owner's 14 Oct direction. Keep excluded sources excluded even when collected or linked by third parties. Queue a particular asset only after its record passes the project rights check; farming's existing explicit batch authorization is separate.

Comlink's own README describes the service as a **binary executable**, not published open implementation source, and lists game-data/profile/event endpoints. Do not call the Comlink binary open-source merely because its documentation is on GitHub. Companion utilities require their own licence check. Some endpoints cause anonymous guest account creation, so deploying/querying them is outside this research authorization. SWAPI's Wookiee encoding is a playful alternative encoding, not a connection to Wookieepedia.

Initial research journal: read supplied screenshot (SWAPI and SWGOH Comlink names), opened supplied URLs and official tool/project pages. Sketchfab collection inaccessible; CGTrader catalogue accessible; source/tool-specific deep audit deferred until a selected use case. No downloads, accounts, contacts, paid calls or installs. This is a saved discovery registry, not a completed catalogue census.
