# Your SWG sandbox

The rebuilt galaxy is running. Reopen every game client to load the new content archives and window settings.

1. Launch **Play SWG.cmd** and log into the owner account.
2. Create a fresh builder with `/object characterbuilder`.
3. Open **MTG Content Library** to browse the 8,051 imported item/schematic entries.
4. For ordinary crafting resources, choose **Deeds > Resource Deed**. Each deed now supplies 100,000 units.
5. For a new perfect-stat test resource, use `/resource perfect steel_duralloy`. Copy the generated resource name from the response, then use `/resource create NAME 100000`.
6. Visit the adapted example quest with `/teleport 3565 -4795 tatooine`. Han Solo and Chewbacca are nearby.

The profile has 5x regular XP, 2x Jedi XP, 1,000 skill points, 15 characters per account/galaxy and four online, one-second prototype/practice crafting, faster factories and shuttles, cheaper training/maintenance, larger house storage and resource stacks, and seven-day Village phases. Existing characters receive the revised skill-point budget after recalculation/relogging. JTL and launch-from-device are enabled for testing.

The imported catalog is a development library. Some definitions are incomplete, acquisition/crafting paths vary, and startup still reports template/asset warnings. Normal gameplay, the example quest, house placement and flight need live tests. Additional ground planets are not enabled merely by collecting their assets.

Use **Back Up SWG Galaxy.cmd** before more edits and **Stop SWG Server.cmd** before rebooting. The clean pre-sandbox snapshot is in **Backups/before-sandbox-and-content-20261013T124400Z**. The complete PDF record and JSON manifests are beside this guide. Keep the owner credentials and backups private.
