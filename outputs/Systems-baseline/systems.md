A slash command marked stub is not necessarily a missing feature: many features run on client packets or radial menus instead.

## Biggest gaps, ranked by effect on play

1. **Space (Jump to Lightspeed)** (row 32, partial). Only partly done and off by default upstream: 22 space combat commands have no script, component repair is a stub, and nothing has been flight-tested here. It is the largest system on the list.
2. **Staff tools** (row 47, partial). 43 of 117 staff commands are still stubs, among them `/money`, `/planetWarp`, `/setRank`, `/grantTitle` and the spawner controls (the audit counted 45; `/spawnStatus` and `/showSpawnRegion` have since been made real locally). This affects running the server every day.
3. **Player cities and Politician** (row 15, partial). Two of eight specialisations (Clone Lab, Entertainment District) cost 80,000 credits and do nothing; militia have no law-enforcement powers; `/cityWarn` and city guards are missing; the weekly cadence hides everything in short tests.
4. **Battlefields** (row 18, stub). Markers only, no rules, and the three battlefield commands do nothing. This is the main pre-CU PvP content gap.
5. **Image Designer** (row 7, partial). The server trusts the client on colour palettes and holo-emote purchases, and stat migration only works in the 4 salon templates. Otherwise the code is complete, not bare bones.
6. **Bounty Hunter** (row 21, partial). No mission failure when someone else kills the target; `bounty_mission_level` is unread.
7. **Creature Handler and pets** (row 23, implemented). Owner priority. The code is complete, but the three CH skill mods (`private_creature_empathy`, `_training`, `_management`) are read nowhere, and pet balance and AI reliability have never been measured.
8. **Gambling** (row 36, partial). Sabacc is commented out; only slot machines and roulette work.
9. **Tutorial** (row 35, disabled). Off by default although the zone is loaded (owner choice).
10. **Stubs to check in game** (row 10, implemented). `/harvesterHarvest`, `/harvesterMakeCrate`, `/harvesterTakeSurvey` and `/lootAll` are stubs that matter only if the pre-CU client sends them: check before building anything.

Deep dive on Image Designer, Politician and thin professions: [id-politician-gaps.md](id-politician-gaps.md).

## Method and caveats

- TODO counts include harmless notes; read the samples in `systems.json` before treating a count as a gap.
